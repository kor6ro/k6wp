| D3 | **Task 1.4 — the DPB-pinned re-encode** | **accepted** | The source of `num_ref_frames` was decided on MEASUREMENT: **ffprobe has no refs/dpb field** (its stream keys were enumerated), **ffmpeg's normal output has none** (the debug log prints the NAL types, not the DPB), and **libmpv has no such property** (the whole property list was enumerated) — the source is therefore **ffmpeg's own `trace_headers` bitstream filter** (`max_num_ref_frames` = 16 for the 4K corpus, 4 for the 1080p one), NOT a hand-written SPS parser.
